## Branching Model
- `main`: stable, reviewed work only.
- `dev`: integration branch for ongoing work.
- `feature/<topic>`: one topic per branch (e.g., `feature/datatypes`).

## How to Work Daily
1. Create/checkout the feature branch: `feature/<topic>`.
2. Commit only topic-specific code.
3. Push branch to origin.
4. Update this README under **Daily Progress** with date + bullet points.
